# Example tasks

Use the dashboard or add a task to `tasks.json`.

```json
[
  {
    "id": "TASK-0001",
    "title": "Plan a week of technology Shorts",
    "kind": "plan",
    "input": "Create 7 video ideas and a repeatable production checklist for a faceless tech channel. I have an Android phone and no budget.",
    "status": "pending"
  }
]
```

Valid kinds: `plan`, `draft`, `summarize_workspace`, `review_output`.

Without a local language model, outputs are templates and checklists, not high-quality generated content.
