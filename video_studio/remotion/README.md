# Stop coding blind — Skill.md voxel remake

A 10-second, 1080×1920, 30 fps Remotion composition based on the root [Skill.md](../../Skill.md). The environment, monitor, keyboard and typing robot are actual React Three Fiber / Three.js voxel geometry; no photographs or image backplates are used. An animated orthographic camera moves through the scene. Words land with spring overshoot, RGB-split impacts and pixel glitches, over faint CRT scanlines.

[View the draft preview and technical report](../../docs/media/remotion/stop-coding-blind-voxel.md). The video is a draft until it is watched and listened to.

## Run

Node.js 20+ and a WebGL-capable browser are recommended:

```bash
cd video_studio/remotion
npm ci
npm run typecheck
npm test
npm run studio
npm run render             # out/stop-coding-blind.mp4
```

Remotion may download a compatible Chrome headless shell on first use. `remotion.config.ts` selects ANGLE for WebGL; on a GPU-less machine, software rendering can be selected with `npm run render -- --gl=swangle`. The 3D scene needs WebGL and will take longer than the former 2D render.

The rendered picture is exactly 300 frames (10 seconds). If an MP4 with an exactly 10.000-second container is required, use a system FFmpeg to copy the rendered video and encode the original soundtrack with a 10-second playback duration:

```bash
ffmpeg -i out/stop-coding-blind.mp4 -i public/audio/stop-coding-blind-120bpm.wav \
  -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 192k \
  -af 'pan=stereo|c0=0.70710678*c0|c1=0.70710678*c0,atrim=duration=10' \
  -t 10 -movflags +faststart out/stop-coding-blind-exact.mp4
```

## Beat and audio

The original instrumental is generated by `npm run audio`, using no outside samples. It is 48 kHz PCM on a 120 BPM grid beginning at time zero. The actual visible word impacts and their RGB/pixel glitches start on successive beats:

| Word | Time | Frame (30 fps) |
|---|---:|---:|
| Stop | 0.5 s | 15 |
| coding | 1.0 s | 30 |
| blind. | 1.5 s | 45 |

Additional short glitch accents occur every two beats. The camera path is frame-derived; the robot's hands alternate and the terminal keeps typing and editing lines of code. The clip has music only: it does not request or generate a voiceover, so the skill's conditional TTS rules do not apply to this clip.

`StopCodingBlind` accepts `audioSrc?: string | null`. Omit it for the bundled track, pass a Remotion `staticFile(...)` URL to substitute a track, or `null` for silence. Replacements must be **120 BPM with beat zero at 0 seconds**; tempo/lead-in detection is not automatic.

## Structure

- `src/storyboard.ts` — exact words and beat events.
- `src/camera.ts` — deterministic 3D camera path.
- `src/PixelAvatar.tsx` and `src/avatarMotion.ts` — voxel character and typing action.
- `src/VoxelWorkspace.tsx`, `src/Voxel.tsx` and `src/terminalMotion.ts` — 3D room, terminal and keyboard.
- `src/GlitchOverlay.tsx` — beat-timed pixel flashes and CRT scanlines.
- `src/StopCodingBlind.tsx` / `src/Root.tsx` — synchronized composition and registration.
- `public/audio` and `public/fonts` — bundled soundtrack and licensed Space Grotesk font.

The root `Skill.md` is copied unchanged from [the specified main-branch version](https://github.com/Ans-to/Youtube-Agent-automation/blob/26fbc5a84d4ea7d093425da165a03715f00fe997/Skill.md). Earlier preview versions remain in Git history. Technical checks do not substitute for visual or audio review.
