# Optional legacy Kani + NeMo Urdu TTS backend; NOT the Windows default.
# The built-in Windows setup uses requirements-urdu-tts.txt (Piper + ONNX Runtime).
# Kani documents Python 3.10–3.12. Install CPU-only PyTorch separately before this file.
#
# Why NeMo 3.x: NeMo 2.4.0 pins `transformers<=4.52.0,>=4.51.0`, and every
# transformers release in that window carries multiple published advisories
# (pip-audit reports ten PYSEC IDs against 4.51.3 alone). NeMo 3.0.0 declares
# `transformers` with no version cap, so it is the only pairing that is both
# resolvable and free of those advisories. The two must be upgraded together:
# pinning an older NeMo re-introduces the vulnerable transformers window.
#
# Known residual advisories, blocked upstream by NeMo 3.0.0's own caps:
#   hydra-core  — NeMo requires `hydra-core<=1.3.2,>1.3`; the fixes are 1.3.4/1.3.6.
#   lightning   — NeMo requires `lightning<=2.4.0,>2.2.1`; the fix is 2.6.6.
#   fsspec      — capped indirectly by lightning<=2.4.0; the fix is 2026.6.0.
#                 Adding `fsspec>=2026.6.0` here makes the file unsatisfiable.
# All three are reachable only by installing this optional backend, which the default
# Windows setup, the CI smoke tests and the shipped renderer never import.
# Re-check with:  pip-audit -r video_studio/requirements-kani-tts.txt
